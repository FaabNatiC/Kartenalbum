# Kartenalbum – Änderungen

## Version 1.5 · 30.10.2026
- Versionshinweis entfernt – Version, Änderungen, Sicherung und Werte jetzt unter dem Info-Knopf oben rechts im Regal (roter Punkt bei Neuerungen)
- Im Set-Album: Liste „Deine Exemplare“ ohne doppeltes Kartenbild
- Im Pokédex: größere Kartenvorschau pro Exemplar, Antippen öffnet die Karte im Set-Album; kein großes Einzelbild mehr

## Version 1.4 · 30.10.2026
- Kartenkopf neu mit Badges: Set und Nummer, Seltenheit, Typ mit Original-Typsymbol, Anzahl im Album
- Preis-Box neu: aktueller Cardmarket-Preis groß, daneben Höchststand seit Erfassung mit Datum
- Preise werden bei jedem Abruf auf dem Gerät mitprotokolliert

## Version 1.3 · 30.10.2026
- Änderungsprotokoll in der App: Versionsnummer unten auf jeder Seite, Hinweis nach jedem Update

## Version 1.2 · 30.10.2026
- Seitliches Verrutschen im Kartendialog behoben (Datumsfeld, iOS-Zoom bei Eingabefeldern)
- Manuelles Wertfeld entfernt – beim Speichern wird automatisch der Cardmarket-Trend übernommen, bei Reverse Holo der Reverse-Holo-Trend
- Neu im Regal: „Alle Werte aktualisieren“ für die ganze Sammlung

## Version 1.1 · 30.10.2026
- Kartenvorschau statt gelber Fläche in der Kartenliste
- Großes Kartenbild im Dialog direkt über die TCGdex-API
- Cardmarket-Preise im Kartendialog: Trend, ab, Ø 30 Tage, Reverse Holo
- „Werte aktualisieren“ pro Set-Album

## Version 1.0 · 30.10.2026
- Erste Version als iPhone-App über GitHub Pages
- Regal mit Pokédex-Ordner (1.025 Pokémon) und Set-Alben für 53 Sets von Schwert & Schild bis Mega-Entwicklung
- Original-Kartenbilder von TCGdex, Deutsch mit englischem Ersatz
- Sammlung nur lokal auf dem Gerät, Sicherung per Export/Import
